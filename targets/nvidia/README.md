# TileFoundry NVIDIA targets

`tilefoundry-nvidia` provides the `cuda` target for TileFoundry. It depends on
exactly the same version of `tilefoundry`.

```sh
pip install "tilefoundry[nvidia]"
```

For development and third-party target packaging, see
[Writing a target](https://github.com/tile-ai/TileFoundry/blob/main/docs/develop.md#writing-a-target).
